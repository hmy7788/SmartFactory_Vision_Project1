# 텀블러 4종 형태 분류 프로젝트 전개 및 결과

## 1. 프로젝트 한눈에 보기

이 프로젝트는 텀블러의 색상, 로고, 손잡이 유무보다 **몸통 윤곽과 비율**을 읽어 형태를 분류하는 컴퓨터 비전 프로젝트이다. 목표는 한 장의 이미지에 담긴 텀블러를 다음 네 형태 중 하나로 분류하는 것이며, 핵심 성능 지표는 각 클래스의 성능을 동일한 비중으로 반영하는 **Macro F1**이다.

| 클래스 | 판별 기준 |
|---|---|
| `straight` | 몸통 아래 지름이 위 지름의 95% 이상이며 윤곽이 거의 수직인 형태 |
| `taper_smooth` | 몸통이 꺾임 없이 점진적으로 좁아지는 형태 |
| `taper_step` | 몸통에 뚜렷한 단차 또는 꺾임이 한 번 이상 있는 형태 |
| `mug` | 손잡이 유무와 무관하게 높이가 지름의 1.5배 이하인 낮고 넓은 형태 |

## 2. 문제 정의와 설계 원칙

일반적인 상품 이미지 분류는 브랜드, 색상, 배경처럼 제품 형태와 직접 관계가 없는 단서에 과도하게 의존할 수 있다. 본 프로젝트는 이를 줄이기 위해 제품의 외곽선, 위아래 폭의 변화, 몸통의 단차, 높이-너비 비율을 중심으로 라벨 기준을 먼저 고정했다.

데이터는 한 이미지에 텀블러 한 개가 명확히 보이고, 상단부터 바닥까지 윤곽을 읽을 수 있는 경우를 우선 채택했다. 심하게 잘린 이미지, 여러 제품이 겹친 이미지, 형태 판단을 방해하는 가림과 흐림은 제외 대상으로 두었다. 손잡이는 `mug`의 보조 단서일 뿐, 최종 판정은 몸통 비율을 우선하도록 정의했다.

## 3. 프로젝트 전개 과정

### 3.1 데이터 수집과 검수 체계 구축

웹 상품 이미지와 실제 촬영 이미지를 함께 활용하기 위해 네이버 쇼핑 API 기반 수집기와 SSG 공개 검색 카드 수집기를 구현했다. 수집기는 후보 이미지 저장, 파일 손상 확인, 해시 기반 중복 제거, 재시도 및 중단 후 재개를 지원한다. 수집 이후에는 검수 기록에 채택 여부, 제외 사유, 크롭 좌표를 남겨 같은 결과를 재현할 수 있도록 구성했다.

웹 데이터는 제품 그룹 단위로 관리했다. 동일 제품의 색상·각도·여백만 다른 파생 이미지가 학습과 검증에 동시에 들어가면 성능이 과대평가될 수 있기 때문이다.

### 3.2 학습 데이터 정제와 분할

최종 웹 데이터는 441장, 368개 제품 그룹으로 정리했다. 각 클래스의 약 20%를 검증셋으로 분리했으며, 분할 기준은 이미지가 아니라 `product_group`이다. 따라서 같은 제품의 유사 이미지가 학습과 검증에 섞이지 않는다.

| 클래스 | 전체 이미지 | 학습 이미지 | 웹 검증 이미지 | 제품 그룹 수 |
|---|---:|---:|---:|---:|
| `straight` | 126 | 101 | 25 | 77 |
| `taper_smooth` | 99 | 79 | 20 | 92 |
| `taper_step` | 108 | 86 | 22 | 94 |
| `mug` | 108 | 86 | 22 | 105 |
| **합계** | **441** | **352** | **89** | **368** |

### 3.3 모델과 전처리 설계

사전학습된 Vision Transformer 계열의 `DeiT-Small/16`을 기반 모델로 사용했다. 입력 이미지는 텀블러의 세로·가로 비율이 왜곡되지 않도록 종횡비를 유지한 상태에서 224 x 224 크기로 패딩한다. 필요할 경우 GrabCut 기반의 실루엣 추출을 적용해 배경 단서의 영향을 진단했다.

모델 학습은 두 방식으로 비교했다.

| 실험 | 학습 방식 | 목적 |
|---|---|---|
| 실험 A | 분류 헤드만 학습 | 사전학습 특징을 고정한 기준선 확보 |
| 실험 B | 마지막 Transformer 블록과 분류 헤드 미세조정 | 텀블러 몸통 윤곽에 더 적합하게 특징을 조정 |

모델 선택에는 검증 Macro F1만 사용했다. 실험 B가 더 적합한 것으로 확인되어 seed 42, 43, 44에서 반복했고, 최종 선택 모델은 `exp_b_seed43`이다.

### 3.4 실제 환경 검증과 오류 분석

웹 검증 성능만으로는 실제 사용 환경의 일반화 성능을 판단하기 어렵다. 따라서 팀원이 보유한 텀블러를 휴대폰으로 촬영한 이미지를 별도의 비학습 테스트셋으로 구성했다. 126장의 리비전 실촬영 이미지와 89장의 웹 검증 이미지를 결합한 215장 통합 평가를 최종 핵심 결과로 사용했다.

오분류 사례는 예측 파일과 혼동행렬로 남겼다. 주요 혼동은 `straight`와 `taper_smooth` 사이에서 나타났으며, 부감 각도 또는 완만한 곡면 때문에 몸통 폭 변화가 달라 보이는 경우가 많았다. 반면 단차라는 뚜렷한 구조적 단서를 가진 `taper_step`은 가장 높은 F1을 기록했다.

## 4. 최종 결과

### 4.1 평가셋별 성능

| 평가셋 | 이미지 수 | Macro F1 | Accuracy | 해석 |
|---|---:|---:|---:|---|
| 웹 검증 | 89 | 0.9678 | 0.9663 | 제품 그룹을 분리한 웹 이미지 성능 |
| 리비전 실촬영 | 126 | 0.8161 | 0.8095 | 실제 촬영 환경에서의 일반화 성능 |
| **통합 평가** | **215** | **0.8784** | **0.8744** | 웹 검증과 실촬영을 결합한 최종 기준 |

통합 평가 Macro F1은 **0.8784**다. 클래스 불균형의 영향을 줄이기 위해 Accuracy가 아닌 Macro F1을 핵심 지표로 삼았으며, 네 클래스 성능이 고르게 유지되는지를 함께 확인했다.

### 4.2 통합 평가 클래스별 성능

| 클래스 | 이미지 수 | Precision | Recall | F1 |
|---|---:|---:|---:|---:|
| `straight` | 64 | 0.8525 | 0.8125 | 0.8320 |
| `taper_smooth` | 52 | 0.7869 | 0.9231 | 0.8496 |
| `taper_step` | 55 | 0.9796 | 0.8727 | 0.9231 |
| `mug` | 44 | 0.9091 | 0.9091 | 0.9091 |

`taper_step`은 단차를 직접적인 형태 단서로 활용할 수 있어 F1 0.9231로 가장 높았다. `mug`는 낮은 높이-너비 비율이 뚜렷해 F1 0.9091을 기록했다. `straight`와 `taper_smooth`는 경계가 연속적이어서 실촬영 조건에서 상호 혼동이 상대적으로 컸다.

### 4.3 소규모 현장 파일럿

실제 보유 텀블러 8개를 6개 촬영 조건으로 찍은 12장 파일럿에서는 Macro F1과 Accuracy가 모두 1.0000이었다. 다만 표본이 매우 작으므로 이 결과는 실제 배치 전 빠른 동작 확인용으로만 해석하며, 최종 성능 주장은 215장 통합 평가를 기준으로 한다.

### 4.4 추론 속도 측정 환경

NVIDIA GeForce RTX 4050 Laptop GPU 환경에서 순수 GPU 추론은 약 39.2ms/장, 초당 약 25.5장으로 측정됐다. 웹 이미지의 전체 전처리와 추론을 합친 경우는 약 58.9ms/장, 초당 약 17.0장이다. 4000 x 3000 실촬영 원본은 전처리 비중이 커 약 795.4ms/장이었으므로, 서비스 적용 전 입력 해상도 축소 또는 제품 영역 추출 최적화가 필요하다.

## 5. 산출물과 재현 방법

저장소에는 데이터 검사, 중복 제거, 제품 그룹 분할, 학습, 단일 이미지 예측, 실제 촬영 평가, 통합 평가, Grad-CAM 시각화 코드를 포함했다. 최종 선택 가중치 `exp_b_seed43_best.pt`, 12장 현장 파일럿 이미지, 성능 리포트와 혼동행렬도 함께 제공한다.

웹 원본 이미지 자체는 수집 출처와 저장 용량 문제로 저장소에서 제외했다. 팀원이 학습을 재현할 때에는 보유한 `raw/` 데이터 경로에 맞춰 `data/metadata.csv`의 `full_path`를 갱신해야 한다.

```powershell
# 환경 준비
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 데이터 검사와 제품 그룹 단위 분할
python -m src.data.inspect_and_clean
python -m src.data.split_dataset

# 모델 비교 학습
python -m src.train --mode compare

# 최종 모델로 단일 이미지 예측
python -m src.predict --image path\to\tumbler.jpg --checkpoint checkpoints\exp_b_seed43_best.pt
```

## 6. 한계와 다음 단계

현재 모델은 웹 상품 이미지에서 강한 성능을 보였지만, 실제 촬영 환경에서는 성능이 낮아졌다. 조명, 카메라 각도, 손 가림, 배경, 제품 표면 반사 등이 도메인 차이를 만들기 때문이다. 다음 단계에서는 실제 촬영 데이터를 추가 수집하고 `straight`와 `taper_smooth`의 경계 사례를 우선 보강해야 한다.

또한 한 장에 여러 제품이 등장하는 상황을 지원하려면 객체 탐지 또는 제품 영역 분할 단계를 분류기 앞단에 추가해야 한다. 현재는 한 개의 텀블러가 중심에 명확하게 보이는 입력을 전제로 한다.

## 7. 결론

본 프로젝트는 형태 기준을 명확히 정의하고, 제품 그룹 단위 분할과 실촬영 평가를 통해 과대평가 가능성을 줄인 텀블러 형태 분류 시스템이다. 최종 모델은 통합 비학습 215장 기준 Macro F1 0.8784를 달성했다. 단차와 낮은 비율처럼 구조적 특징이 뚜렷한 형태는 안정적으로 분류했으며, 앞으로는 실제 촬영 데이터와 경계 사례를 보강해 `straight`와 `taper_smooth`의 혼동을 낮추는 것이 핵심 과제다.
