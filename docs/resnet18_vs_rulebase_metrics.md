# ResNet-18 vs 룰베이스 — 지표 정리 (2026-09-16)

발표자료용으로 이번 세션에서 측정한 모든 지표를 한 곳에 모은 요약 문서.
원본 실험 과정·진단 내용은 `docs/experiment-log.md` 참고.

## 용어

- **테스트1**: 같은 도메인(크롤링 이미지) 분할. `data/preprocess`(642장) 중
  `dl2_resnet/train.py`와 동일한 `stratified_split(val_ratio=0.2, seed=42)`로
  뽑은 Val 127장. 두 트랙 모두 정확히 같은 127장을 사용.
- **테스트2**: 직접 촬영(실사용 환경) 데이터. `data/test1`(158장, 원본 전체)
  또는 사용자가 직접 32장을 걸러낸 `data/test1_orientation_backup`(126장,
  큐레이션본) 두 가지 기준으로 측정.

## 해석 메모

- **테스트1에서도 룰베이스(63.0%)가 ResNet-18(96.9%)보다 크게 낮음** — 크롤링 이미지(정면 카탈로그 컷)에서도 룰베이스의 기하학적 가정이 완벽하지 않다는 뜻.
- **테스트2로 가면 격차가 더 벌어짐** — 룰베이스는 하락폭 44.6~45.5%p로 사실상 붕괴 수준(mug로 쏠림), ResNet-18은 14.4~14.6%p로 상대적으로 견고.
- **두 트랙 모두 taper_smooth가 상대적으로 약한 클래스** — ResNet-18도 테스트2에서 F1 0.69~0.69로 4클래스 중 최저, 룰베이스는 테스트2에서 F1 0(완전 붕괴).
- 큐레이션(158장→126장, 32장 제거)이 전체 경향을 바꾸지 않음 — 두 트랙 모두 오차범위 내 동일한 수치.
